# FireSat II Thermal Exercise

Interactive thermal design page for the thermal subsystem exercises of the Space Systems Engineering HS2026 ETH Zürich.

## Open the exercise here

**https://choucolat.github.io/STK_thermal_exercise/firesat_thermal_design.html**

## What the page covers

The exercise follows the thermal design of FireSat II in six blocks. Blocks 1–2 are done in STK; Blocks 3–6 are done on the page:

| Tab | Topic |
|---|---|
| Block 3 | Heat model: load your STK exports (`hot.csv`, `cold.csv`) and compare the equilibrium, one-node and two-node models |
| Block 4 | Thermal requirements: keep five units in range with optical properties only |
| Block 5 | Thermal hardware: radiator, heaters, washers, straps, MLI within a 2 kg / 14 W budget |
| Block 6 | Testing: IR test setup, test levels, chamber setup and model correlation |

Follow the exercise sheet on moodle for the tasks of each block.

## Beta angle explorer

**https://choucolat.github.io/STK_thermal_exercise/beta_angle_animation.html**

An animation of the beta angle and eclipses for FireSat II's 700 km orbit, in an Earth-centred and a Sun-centred view. Useful for Block 2.

## Example STK exports

`hot.csv` and `cold.csv` are reference STK exports for the hot and cold case. Please make your own exports in Block 3; if your group gets stuck in STK, you can download these two files and load them on the page instead.
